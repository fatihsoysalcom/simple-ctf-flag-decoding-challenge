# Simple CTF Flag Decoding Challenge

This example simulates a very basic Capture The Flag (CTF) challenge, a core concept of platforms like BlackBoxCTF. Participants must decode an encoded message using Base64 to reveal a hidden 'flag' string, demonstrating a common task in cybersecurity practice.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
